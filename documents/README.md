# Documents

This folder is for storing documents that people can access for the AI Agent Build Day.

## Usage

Feel free to add any documents, guides, resources, or files related to the AI Agent Build Day here.

## Organization

You can organize documents into subfolders as needed:
- Presentations
- Guides
- Resources
- Sample code
- Meeting notes

## Contributing

To add a document:
1. Place your file in this folder or an appropriate subfolder
2. Update this README if you create new subfolders or categories
